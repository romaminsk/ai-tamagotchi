# ai-tamagotchi

Тамагочи-питомец на tkinter, реплики которого генерирует **локальная модель
Ollama** (по умолчанию `qwen2.5:3b`). Никаких облаков, ключей и внешних
серверов: игра общается только с localhost. Правила игры держит код — модель
лишь «говорит», состояние питомца никогда не берётся из её ответов. Питомец
не умирает.

Стек: Python 3.10+, только стандартная библиотека (stdlib), без pip-зависимостей.

## Установка

1. Python 3.10+ с tkinter. На macOS, если `python3 -c "import tkinter"` даёт
   ошибку, поставьте `brew install python-tk`.
2. [Ollama](https://ollama.com) и модель:
   ```bash
   ollama pull qwen2.5:3b
   ```
   Скачивание ~1.9 ГБ, идёт с локального пути сервера Ollama (его интернет-
   трафик — только само скачивание модели; самой игре доступ в Сеть не нужен).

## Запуск

```bash
ollama serve                # если сервер ещё не запущен
python3 -m tamagotchi       # из папки репозитория
```

## Управление

| Кнопка / клавиша | Действие |
|---|---|
| «1: Покормить» (1) | покормить питомца (+30 сытости, −3 чистоты) |
| «2: Играть» (2) | поиграть (+25 веселья, −10 энергии, −5 сытости) |
| «3: Спать/Разбудить» (3) | уложить спать или разбудить |
| «4: Помыть» (4) | помыть (+40 чистоты) |
| Escape | сохранить и выйти |

Один игровой тик — 5 секунд. Один тик бодрствования: сытость −1.0, энергия
−0.6, веселье −0.8, чистота −0.5. Во сне энергия +2.5 за тик, при 100 питомец
просыпается сам. Настроение рассчитывается по приоритету: спит > голодный >
грязный > сонный > грустный > счастливый > спокойное.

## Оптимизация локальной LLM

Клиент переводён на нативный `POST /api/chat` (stream=false, keep_alive 10m),
параметры запроса (`temperature`, `top_p`, `top_k`, `repeat_penalty`,
`num_predict`, `num_ctx`) управляются из данных `~/.ai-tamagotchi/
model-settings.json` и из UI. Промпт `optimized` параметризован по длине
(кратко/средне/развёрнуто — до 80/240/520 символов) с few-shot примерами;
baseline-промпт сохранён дословно (`BASELINE_PROMPT`), `--check` и
`--demo-log` работают с текущими настройками.

Панель «Модель» под кнопками действий: температура (±0.1 в 0.1–1.5),
длина реплики, лимит токенов (цикл 60→120→220→320→400), контекст
(2048/4096/8192), пресет «Базовый/Оптим.» и переключение модели из кэша
`/api/tags` (кэш обновляется фоновым потоком; при одной модели кнопка
неактивна). Изменения применяются со следующего запроса и сохраняются в
`model-settings.json`; сетевых вызовов из обработчиков кнопок нет.

Квантование: доступны теги `qwen2.5:3b-instruct-q8_0` (3.3 GB) и
`qwen2.5:3b-instruct-q2_K` (1.3 GB); после `ollama pull` они появляются
в кнопке «Модель ⟳». Подробно: docs/optimization-report.md.

### Бенчмарк

```bash
python3 -m tamagotchi --bench   # до 40 минут, нужна живая Ollama
```

Сравнивает A (baseline) / B (базовые параметры + длинный промпт) / C
(сжатые параметры) / M (medium-режим, 160 токенов) / q8_0 (квантование)
/ E (num_ctx 2048 и 8192); 2 прогона × 6 сценариев на конфигурацию.
Результат: `docs/optimization-report.md` (до/после, правило выбора) и
сырьё `docs/bench-raw.json`. Ключевые замеры одного запуска
(qwen2.5:3b, 100% GPU): A — 3.15 с, 26 симв., 8.2 симв./с; B — 11.31 с,
155 симв., 13.7 симв./с; M-medium — 6.70 с, 90 симв., 13.4 симв./с;
C (long, 220 ток.) — 25.30 с, 392 симв., 15.5 симв./с (выше лимита
15 с); q8_0 — 31.27 с, 12.9 симв./с; E-2048 — 25.99 с, 397 симв.;
E-8192 — 27.61 с, 432 симв. q2_K — 0 из 12 реплик приняты
(иероглифы/латиница) — отброшен, данные прошлого запуска. Правило v2
(принято ≥ 90% и время ≤ 15 с, максимум симв./с) выбрало конфигурацию
B — она записана в пресет OPTIMIZED.


## Переменные окружения

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `OLLAMA_URL` | `http://localhost:11434` | адрес Ollama; разрешён только localhost/127.0.0.1/::1 |
| `OLLAMA_MODEL` | `qwen2.5:3b` | имя модели |
| `LLM_TIMEOUT` | `60` | таймаут запроса, секунд |
| `PET_NAME` | `Пушок` | имя питомца |
| `TAMAGOTCHI_HOME` | `~/.ai-tamagotchi` | куда писать save.json |
| `TAMAGOTCHI_SMOKE` | — | `=1` — GUI-смоук без участия человека (окно, 3 тика, 1 действие, закрыть) |

## Схема работы

```
игра (tkinter, главная петля)          Ollama (localhost:11434)
┌─────────────────────────────┐        ┌──────────────────────┐
│ событие/настройение/действие │-query-▶│ qwen2.5:3b           │
│ воркер-поток + Queue        │        │ chat/completions     │
│ питомец: правила в коде     │◀-фраза-│ максимум 60 токенов  │
│ реплика в речевом пузыре    │        └──────────────────────┘
└─────────────────────────────┘
```

- Запрос генерируется в фоне; ниже 8-секундной паузы между запросами;
  лишние события отбрасываются (максимум один запрос одновременно).
- Ответ модели заменяет мгновенную заготовку. Если Ollama недоступна,
  питомец говорит заготовленные фразы, в углу `LLM: офлайн`, игра
  продолжается и не падает.
- По `stderr` пишется одна строка на запрос: `[llm] событие, секунды, ok/fail`.

## Работает полностью офлайн

Все сетевые вызовы в коде направлены только на `localhost`/`127.0.0.1`/`::1`
(проверяется и тестами, и валидацией конфига: чужие адреса не пропускаются).
В пакете нет `https://`, `api_key`, `Bearer`. Как проверить вручную:

1. Запустите приложение как обычно (`python3 -m tamagotchi`).
2. Отключите Wi-Fi / отключите интерфейс Network — игра продолжает работать.
3. Проверьте, что индикатор `LLM: онлайн`, реплики генерируются (Ollama
   работает локально, ей интернет не нужен после загрузки модели).
4. Выключите `ollama serve` (`pkill -f "ollama serve"`) — индикатор станет
   `LLM: офлайн`, питомец переключится на заготовленные фразы, UI и тик
   продолжат работать. Снова `ollama serve` — индикатор вернётся через ≤30 с.

«Скриншоты» и ручную проверку выполняете вы сами (см. «Скриншоты»).

## Заметка про python-tk на macOS

Если `import tkinter` не работает:

```bash
brew install python-tk
```

Equivalent для python.org-сборок — включите установку Tcl/Tk в Windows-сборке
установщика; для system Python на macOS может потребоваться python-tk из Brew.

## Структура

```
tamagotchi/
  config.py    # переменные окружения и валидация (только localhost)
  pet.py       # правила игры: тики, действия, настроение (чистый код)
  fallback.py  # фразы-заготовки на офлайн и мгновенную реакцию
  llm.py       # клиент Ollama, планировщик, фоновый воркер
  sprite.py    # чистые параметры рисунка по настроению
  ui.py        # окно tkinter: Canvas, полосы, кнопки, пузырь
  storage.py   # save.json (атомарно), офлайн-тикация (потолок 30)
  __main__.py  # CLI: запуск, --check, --demo-log, TAMAGOTCHI_SMOKE
tests/         # unittest, без сети и GUI
```
